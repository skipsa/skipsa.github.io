WS2 — GitHub Pages upload
=============================

Target URL: https://slama.one/ws2

Upload the entire "ws2" folder to the root of your GitHub Pages repository.
The root should then contain:

  /index.html
  /CNAME
  /ws2/index.html
  /ws2/images/
  /ws2/downloads/

The images/ folder contains optimised 1800 px gallery files.
The downloads/ folder contains the supplied 2500 px files.
Do not rename or move files inside the ws2 folder unless you also update index.html.
