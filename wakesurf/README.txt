WAKESURF PHOTO GALLERY

Upload the complete “wakesurf” folder to the root of your GitHub Pages repository.

The page will be available at:
https://slama.one/wakesurf

Folder structure:
wakesurf/index.html
wakesurf/images/ (full-size originals)
wakesurf/thumbs/ (optimised gallery previews)

The page uses JSZip from jsDelivr to create ZIP files in the visitor’s browser. An internet connection is therefore required when using the download-selected function.
